# Protótipo

Prints do protótipo no Figma, exportadas em 2026-11-17.
Referência visual para as telas; o Figma continua sendo a fonte.

| Arquivo | Tela |
|---|---|
| `01-lista-canticos.png` | Lista de cânticos, busca e abas Cânticos / Setlists |
| `02-cantico.png` | Cântico com cifra sobre a letra, Tom, Tamanho, Letra e cifra / Só letra |
| `03-trocar-tom.png` | Trocar tom: meio tom para cima ou para baixo, voltar ao original, prévia |
| `04-tamanho-letra.png` | Tamanho da letra em 5 níveis, com prévia |
| `05-setlists.png` | Lista de setlists e "Nova setlist" |
| `06-setlist-detalhe.png` | Setlist com reordenação e "Abrir o primeiro cântico" |
| `07-sem-internet.png` | Aviso de sem internet para cântico ainda não aberto |
